# Security Policy

## Supported versions

Security fixes are currently provided for the latest code on the `main` branch.
This project is in beta; other branches and releases may not receive security
updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Use GitHub's private vulnerability reporting feature for this
repository. If private reporting is unavailable, contact the repository
maintainers privately through GitHub before sharing vulnerability details.

Include the affected version or commit, the impact, and steps to reproduce.
Please allow maintainers reasonable time to investigate and prepare a fix
before making a vulnerability public. Do not include real user data, secrets,
or other sensitive information in a report.
